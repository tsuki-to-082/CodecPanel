# Codec Panel

AndroidのBluetoothオーディオコーデックと伝送設定を確認・変更するアプリです。

**現在の配布版：1.0.2 ベータ1（1.0.2-beta.1）**  
**作者：月澄(つきと)**

このリポジトリはAPKと説明の配布用です。アプリのソースコードは公開していません。

## ダウンロード

このリポジトリの **Releases** を開き、利用するバージョンの **Assets** から `CodecPanel-1.0.2-beta.1-release.apk` をダウンロードしてください。

`Source code (zip)` と `Source code (tar.gz)` はAndroidアプリのインストーラーではありません。インストールには `.apk` ファイルを使います。

ベータ版は **Pre-release** と表示します。正式版の公開後も、同じリポジトリのReleasesで配布します。

## 主な機能

- 接続中のコーデック、サンプルレート、ビット深度、チャンネルの表示
- 現在の接続で利用可能なコーデックへの切り替え
- 対応するサンプルレート・ビット深度・チャンネルの選択
- LDACの通信品質の選択と、伝送設定のリセット
- 対応機器のバッテリー残量表示。取得可能な場合は左右・ケースを個別表示
- ライト／ダーク表示と、4種類のアプリアイコン
- タスク終了後の新しい起動時の短いアニメーション
- 報告文のコピーとフォームを開く操作を分けたバグ報告
- 新しい安定版のお知らせと、オフラインで読めるパッチノート

設定の変更と残量表示は、Android・接続機器・権限が対応する範囲で利用できます。数値はAndroidや機器が報告する情報で、実測の通信速度や音源の品質を表すものではありません。

## 利用環境と使い方

- Android 12以降
- 音楽用に接続したBluetoothオーディオ機器
- コーデック操作には、アプリ内の案内に従った接続方式の設定が必要です。Shizuku方式の手順を用意しています。

[セットアップと更新の手順](docs/SETUP_ja.md)

対応端末・機器の確認を進めているベータ版です。表示や切り替えの結果に問題があれば、下記の方法でご報告ください。

## 新しい安定版のお知らせ

この版は、アプリを開いたときに1日1回までGitHubの安定版を確認します。新しい安定版がある場合は、コーデック画面に案内を表示し、**ダウンロード** からその配布ページを開けます。**設定 → アプリの更新** から手動確認や自動確認のオン・オフもできます。

ベータ版は案内の対象に含めません。アプリを閉じている間の定期確認はなく、次に開いたときに確認します。更新確認で機器名・Bluetoothアドレス・診断情報は送信しません。APKのダウンロードとインストールは利用者が行います。

ベータ1・ベータ2にはこの機能がありません。今後の安定版の案内を受け取るには、まず1.0.2-beta.1へ手動で更新してください。

## パッチノート

更新後の起動時に、その版の変更点の案内を表示します。**パッチノートを見る** から読めます。読んだり **閉じる** を押した後は同じ版の案内を繰り返さず、**設定 → パッチノート** からいつでも読み直せます。履歴はアプリ内に同梱しているため、通信なしでも読めます。

[パッチノートの履歴](docs/PATCH_NOTES_ja.md)も公開します。新しい安定版の案内では **更新内容を見る** から、そのリリースの変更点を開けます。ベータ版も各GitHubリリースの説明に変更点を掲載します。

## バグ報告・お問い合わせ

1. アプリの **設定 → バグ報告** で、発生した問題と再現手順を入力します。
2. プレビューを確認し、**報告内容をコピー** を押します。フォームは開きません。
3. **フォームを開く** を押します。クリップボードの内容は変更されません。
4. フォームの **報告内容** に貼り付け、必要なら備考を追加して送信します。

[Codec Panel 報告・問い合わせフォーム](https://forms.gle/GGoeg9g6n83f7d4v5)

診断情報の添付は任意です。アプリが生成する診断情報には機器名とBluetoothアドレスを含めません。手入力した情報はそのまま報告文に入るため、送信前に確認してください。返信用メールアドレスは任意で、その報告または問い合わせへの返信のみに使用します。

その他の問い合わせも同じフォームで受け付けます。**報告内容** に「お問い合わせ」と書いたうえで内容を入力し、送信してください。返信を希望する場合は、任意の返信用メールアドレス欄に連絡先を記入してください。
