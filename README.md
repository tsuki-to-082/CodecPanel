# Codec Panel

AndroidでBluetoothオーディオの**コーデック情報を確認・切り替え**たり、伝送設定を確認・変更したりできる無料アプリです。

**最新の安定版：v1.0.5** ｜ **対応OS：Android 12以降** ｜ **非公式アプリ**  
開発・配布：**月澄（つきと）**

## 主な機能

- **コーデックの確認・切り替え**：現在のBluetoothオーディオコーデックを表示し、端末と接続機器が対応する候補から選択できます。
- **伝送設定の確認・変更**：サンプルレート、ビット深度、チャンネル、対応するLDAC通信品質などを確認・調整できます。
- **接続機器の情報**：機器名や取得可能なバッテリー残量を表示します。対応機器では左右・ケースの残量も確認できます。
- **再生中のメディア**：曲名・アーティスト・ジャケット画像・再生位置を表示。対応する再生アプリでは再生／一時停止、前後の曲への移動も操作できます。
- **ホーム画面ウィジェット**：コーデックや接続機器の情報、再生中メディアを表示。サイズ変更にも対応しています。
- **表示のカスタマイズ**：ライト／ダークテーマ、アプリアイコン、3種類の再生位置デザイン（ライン／ドット／ジャケット外周）を選べます。
- **更新情報・サポート**：安定版の更新案内、パッチノートの閲覧、バグ報告・お問い合わせに対応しています。

**ご注意：** 表示するコーデックや伝送設定の値はAndroid・接続機器から取得した情報であり、実測したビットレートや音源品質を示すものではありません。利用できる機能は端末・OS・接続機器・再生アプリによって異なります。

## 使い始めるには

1. AndroidのBluetooth設定から、イヤホン・ヘッドホンなどの音楽用Bluetooth機器を接続します。
2. Codec Panelを起動し、必要な権限を許可します。
3. アプリの **設定 → 接続方法** で、お使いの端末に合った接続方式を設定します。
4. メイン画面でコーデックや接続機器の情報を確認します。

コーデックの取得・切り替えには端末に応じた設定が必要です。**Shizuku** を利用する方式も用意しています。**機器登録による接続方式は試験機能**です。

曲情報の表示と再生操作を使う場合は、**設定 → 再生中のメディア** をオンにし、Androidの通知アクセスを許可してください。再生位置は表示専用で、バーを操作して曲の再生位置を変更する機能はありません。
