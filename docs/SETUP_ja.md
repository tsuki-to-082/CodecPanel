# Codec Panel 1.0.1-beta.1 ベータ版の使い方

## インストール

1. [正規の配布元のGitHub Releases](https://github.com/tsuki-to-082/CodecPanel/releases)を開きます。
2. Assetsから、末尾が `-release.apk` のAPKをダウンロードします。ファイル名の新しい形式は `CodecPanel-1.0.1-beta-release.apk` のように `beta` の後ろに番号を付けません。既存リリースでは旧表記のファイル名が残る場合があります。
3. ダウンロードしたAPKを開きます。Androidから求められた場合は、そのブラウザーやファイルアプリからの「不明なアプリのインストール」を許可します。
4. Androidのインストール画面を確認し、インストールします。

対象はAndroid 12以降です。GitHubが用意する `Source code` のZIPや、この配布セット全体のZIPはAPKではありません。

## Bluetooth機器と接続する

1. AndroidのBluetooth設定でイヤホン・ヘッドホン・Bluetooth DACなどを音楽用に接続します。
2. Codec Panelを開き、Bluetoothの許可を与えます。
3. アプリの **設定 → 接続方法** を開き、接続方式を設定します。
4. Shizuku方式を使う場合は、**Shizukuのセットアップ** に従って起動と許可を完了します。

Shizukuは別のアプリです。[公式ダウンロード](https://shizuku.rikka.app/download/)と[公式の起動手順](https://shizuku.rikka.app/guide/setup/)も参照できます。ワイヤレスデバッグで開始したShizukuは、スマホの再起動後に起動し直します。

複数の音楽用機器が接続されている場合は、**機器を選ぶ** で対象を選択します。

## コーデックと伝送設定

**利用可能なコーデック** から、接続先とAndroidが対応するコーデックを選択します。変更後は、Androidから読み直した現在の設定を確認します。

**伝送設定** では、対応する値だけ選べます。

| 項目 | 選択内容 |
| --- | --- |
| サンプルレート | 自動、または接続で対応するkHzの値 |
| ビット深度 | 自動、または接続で対応する16／24／32 bit |
| チャンネル | 自動／モノラル／ステレオのうち接続で対応するもの |
| LDAC通信品質 | 自動／音質優先／バランス／接続優先 |

ビットレートの手動選択はLDACの品質設定に対応します。表示するビットレートは目標値で、実測した速度ではありません。

伝送設定の右上の **リセット** は、現在のコーデックを保ち、対応する項目を自動選択へ戻します。自動で選ばれる値はAndroidと接続機器によって異なります。

## バッテリーと表示

残量を取得できる機器ではバッテリーを表示します。左右・ケースの情報が取得できる場合は個別に表示します。機器が報告しない値は推定せず、未取得の表示にします。

- 11〜20%：黄色
- 0〜10%：赤色

設定からテーマとアプリアイコンを変更できます。起動アニメーションは約1.3秒で、新しいタスクとして起動したときに再生します。ホームからの復帰では繰り返しません。

## 不具合を報告する

**設定 → バグ報告** で入力し、プレビューを確認します。**報告内容をコピー** で報告文をコピーします。次に **フォームを開く** で[作者のGoogleフォーム](https://forms.gle/GGoeg9g6n83f7d4v5)を開きます。フォームを開いてもクリップボードの内容は変更しません。

**報告内容** に貼り付け、必要なら **備考** を追記し、フォームで送信してください。コピーとフォームを開く操作だけでは送信は完了していません。

診断情報の添付と返信用メールアドレスの記入は任意です。返信用メールアドレスは、その報告または問い合わせへの返信のみに使用します。

## お問い合わせ

使い方・プライバシー説明・利用条件などに関する問い合わせも、[作者のGoogleフォーム](https://forms.gle/GGoeg9g6n83f7d4v5)で受け付けます。**報告内容** に「お問い合わせ」と書いたうえで内容を入力し、送信してください。返信を希望する場合は、任意の返信用メールアドレス欄に連絡先を記入してください。

## 更新

新しい安定版が公開されると、アプリを開いたときにコーデック画面へお知らせを表示します。自動確認は初期状態でオンで、1日1回までです。アプリを閉じている間は定期確認しません。ベータ版は案内の対象に含めません。

**ダウンロード** を押すと、その安定版のGitHub配布ページがブラウザーで開きます。Assetsから公開用APKをダウンロードして開き、Androidの画面で **更新** を選びます。APKの自動ダウンロード・自動インストールは行いません。

**設定 → アプリの更新 → 更新を確認** で、その時点の公開状況を手動で確認できます。同じ設定画面で自動確認をオフにできます。「あとで」で閉じたお知らせは、さらに新しい安定版が出るか、手動で確認するまで表示しません。

ベータ1・ベータ2には更新のお知らせ機能がないため、まず1.0.1-beta.1へ手動で更新してください。

同じ公開用アプリIDと署名で、版番号を増やしたAPKを使用することで、設定を保ったまま更新できます。

## パッチノートを読む

この版を初めて開くと、コーデック画面に変更点の案内を表示します。**パッチノートを見る** で現在の版と過去の配布版の変更点を読めます。**閉じる** または閲覧後は、同じ版の案内を繰り返しません。**設定 → パッチノート** からいつでも読み直せます。アプリ内の履歴は通信せずに表示します。

安定版の更新案内の **更新内容を見る** は、その安定版のGitHubリリースをブラウザーで開きます。各ベータ版の説明と履歴も、パッチノート画面の **GitHubのパッチノートを開く** から確認できます。
