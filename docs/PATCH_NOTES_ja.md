# Codec Panel パッチノート

作者：月澄(つきと)

## 1.0.1-beta.1 — 1.0.1 ベータ1

2026年10月12日作成

### 新機能

- 新しい安定版をアプリ内でお知らせします。設定から手動確認と自動確認のオン・オフを選べます。
- 設定にパッチノートを追加しました。更新後の起動時に変更点の案内を表示し、あとからいつでも読み直せます。
- 安定版の更新案内から「更新内容を見る」で、その版のGitHubパッチノートを開けます。

### 改善

- バグ報告の「報告内容をコピー」と「フォームを開く」を別のボタンにしました。フォームを開いても、クリップボードの内容を変更しません。
- 配布元・報告先・更新手順の説明を整理しました。

### 更新と確認について

- 更新のお知らせは安定版が対象です。ベータ版はGitHub Releasesから手動で更新してください。APKの自動インストールは行いません。
- 既存の公開ベータ版に上書きできます。
- 更新のお知らせは、安定版を公開してからの実機確認が残っています。

## 1.0.0-beta.1 — 最初の公開ベータ版

2026年10月11日公開

### 配布開始

- Android 12以降向けのベータ配布を開始しました。
- コーデック・伝送設定の変更、対応機器の残量表示、ライト／ダーク表示、4種類のアイコン、バグ報告を利用できます。

新しい版の変更点は、[GitHub Releases](https://github.com/tsuki-to-082/CodecPanel/releases)にも掲載します。アプリ内では **設定 → パッチノート** から読み直せます。
